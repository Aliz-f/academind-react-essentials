# React Essentials

A React project covering fundamental concepts: Components, JSX, Props, and State.

Built with **Vite**, **React**, and **Tailwind CSS v4**.

## Live Demo

[react-essentials.arfadaei.ir](https://react-essentials.arfadaei.ir)

## Getting Started

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview
```

## Deploy to GitHub Pages

```bash
npm run deploy
```
